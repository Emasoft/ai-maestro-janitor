# TRDD-ce195129 — Memory system design + measurement loop

## ⏵ STATE — READ THIS FIRST ON RESUME (authoritative) — 2026-06-06

**Goal (USER, /goal 2026-06-06):** iterate with the dual-test method and STEER the design of the
markdown memory system, improving it and MEASURING improvements against five criteria:
1. **Faithfulness** of recalled data (matches source-of-truth, undistorted).
2. **Correctness** of recalled data.
3. **Efficiency** of the retrieval tools (latency / token cost).
4. **Agent-usability** of the retrieval tools (can an agent drive them right from minimal text?).
5. **Skill brevity** — "the shorter the skill text to learn using it IN FULL, the better designed."

**Method (recorded as the standing practice):** the dual-test evaluation —
`~/.claude/.../memory/feedback_memory_dual_test_evaluation.md`. Run BOTH cold-recall (query from
the QUESTION/symptom vocabulary only) and write-then-recall (author then retrieve); judge BOTH the
agent's search strategy AND the system's retrieval; index notes by question/symptom, not answer
jargon; only ship a tool fix a cold-start (uncontaminated) query justifies.

**Components & status:**
- QUERY ENGINE — `memgrep` (TRDD-d151fe52): grep + markdown-structural filters + boolean `--where`
  (incl. link semijoin) + index/links/fact subcommands. Essentially built; 41 tests, clippy clean.
  SIGPIPE broken-pipe fix shipped (commit 38f5905) — surfaced by dogfooding recall.
- SKILL (teaching text) — `tools/memgrep/SKILL.md`. THIS is the artifact criterion-5 measures.
- KB CONTENT — the symptom-indexed `memory/*.md` notes. Seeded: keychain-arch + dual-test method.
  Gap: breadth.
- RECALL TRIGGER — a SessionStart/on-demand step running frontmatter-gated symptom queries. NOT
  built yet.

**NEXT ACTION:** continue the measure→improve→measure loop on `tools/memgrep/SKILL.md` (shorten
further without losing completeness), then build the recall trigger, then broaden the KB. Each
iteration logs its metrics below.

**Load-bearing finding (verified, not asserted):** the FLAG surface and the `--where` predicate
surface are ISOMORPHIC — every `--flag v` equals the predicate `flag "v"` (negatives via `not`);
the only `--where`-only predicates are the 5 file-level ones (path/name/fm/links-to/linked-from).
Verified 2026-06-06 by 4 equivalence counts (`--heading --no-code` == `--where 'heading and not
code'`, etc., all matched). ⇒ teach `--where` by DERIVATION from the flags, never re-enumerate —
shorter AND truthful. This is the central skill-brevity lever.
