## Scope

The merge executor: a skill that consolidates same-subject + same-type notes,
deduplicating lessons, redirecting all backlinks, and preserving ocd/lmd, all
through the TRDD-A transaction core — plus its `verify_merge` predicate.

## Key mechanisms

- `skills/janitor-memory-consolidate/SKILL.md`: incremental (recent-N → memgrep
  narrow same-scope → read the small set → merge ONLY same-subject AND same-type);
  **abstain-on-uncertain** default; pre-merge no-third-page check; intra-page dedup
  (keep better-sourced `[^N]`); **redirect all backlinks** `[[A]]`/`[[B]]`→`[[C]]`
  and grep cross-scope PROSE mentions → surface; `ocd=min`, `lmd=today`, `[^N]`
  verbatim; `is_legal_merge` refusal; EXIT/retry/rollback. Runs through TRDD-A.
- `verify_merge` in `memory_edit_verify.py` (content-union, no-third-page, dedup,
  link-redirect, ocd-min).

## Acceptance

- Same-subject + type → merged, deduped, backlinks redirected, ocd=min.
- Cross-type / cross-scope → refused.
- Uncertain → abstain.
- DROP / REWORD → FAIL.
