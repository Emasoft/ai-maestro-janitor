# memgrep structural verbs refuse a page whose page-level lesson is uncited although lint rates that shape INFO

Symptom: memgrep split/merge/migrate/delete refuse any page carrying an uncited page-level [^N]: lesson, even though lint rates that shape INFO and the spec calls it the NORMAL case (Notes section mandatory even when empty). Root cause: footnote_integrity_violations (scripts/memgrep/src/memory.rs, was lines 4123-4158) flagged BOTH a dangling reference (real corruption) AND an unreferenced definition (legal, blessed shape) as violations, and every structural verb bails on any non-empty result. Fix: narrowed the shared guard to flag only dangling references; verified next_footnote_label already scans both defs and refs so an orphan def can never collide during a move/renumber. Added Rust unit tests proving an uncited lesson passes and a dangling reference still fails, plus an end-to-end migrate_compute regression test. Link: GitHub issue 304 on Emasoft/ai-maestro-janitor.
