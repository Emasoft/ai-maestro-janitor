## Design

- Remove from report-sanitizer sanitize_reports.py: the project-root mask to $CLAUDE_PROJECT_DIR (lines 258-260), the plugin root and data masks (262-266), the project folder-name mask (268-269), TMP_VAR to $TMPDIR (67, 276), TMP_CLAUDE, the claude temp-folder mask (68, 277), VOLUME, the volume-name mask (70, 279).
- Keep and move into the shared core: USER_PATH (69, 278) and the home literal (272-274), both to the tilde prefix; SLUG_OTHER (66, 271), which turns a Users-<name> project folder name into Users-USER; the Windows home becomes %USERPROFILE% with the original separator kept.
- Count: the earlier 62 was 45 shield kinds plus 17 sanitizer rules; 3 rules repeat a type, so 59 distinct types; removing the 5 path types leaves 54 types, all in the shared core, detected and redacted by both tools.
- Secret gaps to close in the core: cookie values; a bare Bearer token holding a digit; lower gh_ and hf_ minimum lengths; SSH public key blobs; payment cards; the email rule keeps git-over-SSH clone addresses readable; account name and hostname passed in by the caller.
- Card rule (increment 1, in hooks/secret-shield/cards.ts as redactCards; not yet called by redact() or the live mod): a bare run of 13 to 16 digits; a run of 17 to 19 digits only with a card word (card, credit, debit, visa, mastercard, amex) as a whole word within 32 characters before it on the same line, where an underscore beside the word, or a literal backslash escape (a backslash then n, r or t, any case) before it, counts as a word boundary. Grouped forms use one separator kind: 4-4-4-4, 4-6-5, 4-6-4, 4-4-4-4-3, the longest tried first. A number does not start after a letter, digit, underscore or dot, nor after a separator that follows a digit. A bare run ends where its digits end; a grouped number is refused only when the same separator, a group of 4 or more digits, the same separator and a digit follow, so an expiry, a CVV or one trailing 4-digit group stays visible beside the hidden card. Every hit passes issuer_ok and luhn_ok, ported from report-sanitizer. Known misses: hooks/secret-shield/KNOWN-MISSES.md. Measured 2026-11-16 on 50,487 text files, the old report-sanitizer card rule hid 240 matches: 190 false (180 cargo build hashes, 8 decimal fractions, 2 process-listing columns) and 50 synthetic fixtures; 183 of the 240 were runs of 17 to 19 digits. The 2026-11-17 re-measure of this code is in the Approval log. Of the 28,249 candidate digit runs the old rule read, 23,599 were 19 digits.
- One source per rule within the shield core and report-sanitizer; the janitor Python files secret_names.py and privacy_patterns.py stay separate until TRDD-NRF7OJ5H scope 4. Parity test: one fixture set, built from fragments, run in both repos with byte-identical output.
