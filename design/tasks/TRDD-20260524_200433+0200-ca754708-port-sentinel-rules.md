## Goal

The janitor's `janitor-github-workflow-doctor` skill already runs a
"second pass" regex classifier (`scripts/lib/zizmor_classifier.py` +

zizmor as the authoritative source when present and the janitor pass as the
always-available fallback + janitor-extension catcher.

## Key design insight carried over from Sentinel

Sentinel detects template-injection via a **precise allowlist of
attacker-controllable contexts** (`DANGEROUS_CONTEXTS`), NOT a broad
`{{ ... request ... }}` substring match:

```
github.event.pull_request.title / .body / .head.ref / .head.label
github.event.issue.title / .body
github.event.comment.body
github.event.review.body
github.event.discussion.title / .body
github.event.workflow_run.head_branch
github.head_ref
```

This is exactly the FP-resistant approach that the CPV SkillAudit matcher
(issue #40) gets wrong. Our port uses the precise list, so the janitor's
own injection rules will NOT false-positive on safe expressions like
`github.event.pull_request.number`.

## Architecture (two tiers, one Finding type, one CLI)

Reuse `Finding(rule_id, line, col, matched_text, severity, description)`
from `zizmor_classifier.py` for ALL findings.

1. **Regex tier — `scripts/lib/zizmor_patterns.py`** (existing RE2 RegexSet
   engine). Add the regex-amenable Sentinel rules here. Zero per-rule cost:
   the classifier compiles one combined `(?m)` alternation.

2. **Structural tier — `scripts/lib/sentinel_structural.py`** (NEW). A
   YAML-walking module for rules that need job/step/trigger context or
   absence checks (a RegexSet finds matches, not absences). Parses with
   `yaml.safe_load`, walks `jobs`/`steps`/`triggers`/`permissions`, and
   yields `Finding`s with 1-indexed line numbers resolved from the raw
   text. Mirrors Sentinel's `lib/workflow.rb` helpers + `concerns/
   guard_patterns.rb` (in_run_block?, guarded_by_safe_event?,
   safe_trigger_only?).

3. **CLI — `scripts/doctor_classify.py`** (existing). Run BOTH tiers, merge
   findings, keep JSON-lines output + exit-code contract (0 clean / 1
   findings / 2 no-workflows / 3 internal error). Add `pyyaml` to the PEP
   723 deps.

4. **Recipes — `skills/janitor-github-workflow-doctor/references/`**. Port
   the fix recipes from Sentinel `bot/rules/*.md` (adapted, deduped against
   the existing `zizmor-audit-fix-recipes.md`). Keep SKILL.md ≤ 5000 chars
   (progressive disclosure — recipes live in references, SKILL.md embeds
   their TOCs).
