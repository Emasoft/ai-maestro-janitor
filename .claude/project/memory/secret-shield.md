# secret-shield


^ATOM-DTJY-D7IN [desc: "secret-shield is a vendored upstream mod (MIT) that replaces secrets in tool output with [JANITOR-REDACTED:<type>]; known gaps in KNOWN-MISSES.md", keywords: where_is_the_janitor_secret_shield secret_token_showed_up_in_tool_output what_is_a_JANITOR-REDACTED_marker JANITOR-REDACTED:<type>_marker vendored_secret-shield_mod Singh-AP_awesome-claude-mods_secret-shield hooks/secret-shield which_secrets_does_the_shield_miss KNOWN-MISSES.md session.append_tool-result_redaction secret_redaction_in_tool_output API_key_leaked_in_transcript, type: reference, trdd: TRDD-M1218EMH, ocd: 2026-11-15, lmd: 2026-11-15]
hooks/secret-shield/ is a Claude Code mod vendored from Singh-AP/awesome-claude-mods mods/safety/secret-shield 1.0.0 (MIT; hooks/secret-shield/LICENSE and NOTICE), extended with rules/ files by token category. It replaces secrets found in tool output with the marker [JANITOR-REDACTED:<type>]. Secrets it knowingly does not hide are listed in hooks/secret-shield/KNOWN-MISSES.md (34 entries at 2026-11-15, each with a named test). The mod redacts through two doors in register.ts: the session.append hook (every stored row) and the tool.call hook (successful results only; an error result is returned exactly as core gave it, TRDD-337UVA3J). The error text reaching the model is redacted by session.append; the register.ts comment says this was proven for Bash on Claude Code 2.1.318 and that whether the stored jsonl structured toolUseResult keeps the raw text is unverified. Options in .claude-plugin/plugin.json userConfig: secret_shield_enabled (default true), secret_shield_block_files (default false; also refuses Read, Edit, Write and NotebookEdit on files that usually hold secrets), secret_shield_redact_prompts (default false; also redacts secrets pasted into the user own prompts). Their descriptions say "Not active yet" until the mod is wired. The slash command /janitor-secret-shield (registered in hooks/secret-shield/register.ts) shows what the shield has hidden, or dry-runs it with "/janitor-secret-shield test <text>". [^4]
